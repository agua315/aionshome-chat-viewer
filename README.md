# 聊天记录查看器

独立浏览和搜索 AionsHome 原始聊天记录的 Windows 小工具。AionsHome 后端关闭后，也能查看已保存的文字和本地附件。

## 省流版

- **看和搜**：完整聊天记录、关键词搜索、Markdown / 小说阅读，小剧场可以选章节看。
- **换外观**：五套主题、自定义 CSS 多预设、自己的聊天背景图。
- **导出分享**：TXT、DOCX、PPTX、EPUB、PDF，或把喜欢的话做成一张长图；支持选字和批量马赛克。
- **编辑原文**：可以修改聊天，自选是否保留修改前的原文，以及存档位置。
- **手机也能看**：同一 Wi-Fi 或 Tailscale 下用浏览器打开，不用把记录导入手机；电脑和查看器需要开着。

**第一次使用**：准备 Node.js 24 或更新版本及 Edge / Chrome → 下载源码 → 复制 `config.example.json` 为 `config.json`，填好数据目录 → 双击 `启动聊天记录查看器.cmd`。详细步骤见[下载后启动](#下载后启动)。

## 下载后启动

1. 安装 **Node.js 24 或更新版本**，以及 Edge 或 Chrome。源码已在 Node.js v24.16.0 下验证。
2. 克隆本仓库，或从 GitHub 的 **Code → Download ZIP** 下载并解压。
3. 将 `config.example.json` 复制为 `config.json`，把 `dataDirectory` 改成你自己的 AionsHome `aion-chat/data` 目录。例如：

   ```json
   {
     "dataDirectory": "D:/AionsHome/aion-chat/data",
     "port": 4328,
     "backupDirectory": "",
     "backupEnabled": true
   }
   ```

4. 双击 `启动聊天记录查看器.cmd`，自动打开独立窗口。关闭运行面板即可停止，也可以双击 `停止聊天记录查看器.cmd`。

所需组件已随源码附带，**无需运行 `npm install`**。也可以在程序目录运行 `npm start`。

如果电脑已有便携环境，可将 `node.exe` 放入 `runtime` 目录；启动脚本会优先使用它，否则使用系统安装的 Node.js。仓库不包含运行环境二进制文件、本机配置或聊天数据。

## 使用

左边选择会话，右边看记录。“最早 / 最新”跳到会话两端，“加载更早 / 更新的记录”继续翻看。

在顶部输入关键词，点击搜索或按回车。点击左边的结果，在右边看命中的原话和上下文；可继续向前或向后加载。`Ctrl + F` 聚焦搜索框。

左侧“小剧场”按故事列出已写完的正文；点故事从首章开始，顶部章节下拉框列出这本故事所有可阅读章节，选择后直接跳到章首。“上一章 / 下一章”按目录切换，连续滚动时目录跟随当前章；电脑和手机均支持。也可使用“首章 / 末章”或继续加载翻阅。搜索范围可选“全部记录”“当前会话”或“小剧场正文”，命中后直接定位到章内的高亮文字。正文直接读取本地 `theater_studio` 章节，不需要 AionsHome 后端运行。正常生成结束的 `draft` 和已确认完成的 `ready` 章节可以阅读；正在生成、已中断或仅有计划的章节不显示。章节在查看器中仅供阅读，修改仍使用 AionsHome 的小说编辑功能。

点击顶部“显示设置”，选择“聊天气泡（原文）”“聊天气泡（Markdown）”或“小说阅读（Markdown）”。Markdown 显示加粗、斜体、引用、列表、表格、代码块和链接；小说阅读去掉气泡边框，使用较宽的正文、衬线字体和更舒展的行距。搜索仍可定位渲染后的关键词。

你的发言可放左边或右边，可分别隐藏你的名字、你的头像和角色头像。角色名字保留，方便区分群聊中的不同角色。头像直接读取 AionsHome 的本地文件，缺失时使用名字首字。设置保存后立即生效，存入本程序的 `config.json`，重启后保留；切换格式不修改聊天正文，编辑框始终显示完整原文。

“隐藏系统消息”同时隐藏查看监控、查看动态等系统提示和后台监控触发记录，搜索和翻页也会过滤。只按消息的系统身份过滤，角色的正常回复仍然保留。取消勾选可以再次查看完整记录。

“默认收起监控截图”默认开启：显示系统消息时，监控图片先显示一行“监控截图 · 点击展开”，主动点开后才加载图片，再点可收起。支持摄像头附件和旧的监控截图，也适用于正文中的本地图片标记；普通聊天照片正常显示。这两个选项互相独立，所有阅读样式都支持。

点击消息旁的“编辑”，修改完整正文后点击“保存修改”，或按 `Ctrl + Enter` 保存。“取消”不会写入记录。

点击顶部“存档设置”，选择是否在编辑前保留原文，并选择存档文件夹。Windows 可以点击“选择文件夹”打开系统选择窗口，也可以直接输入绝对路径。设置保存后立即生效，重启仍然保留。

首次使用默认开启原文存档，位置为当前使用者的 `文档/AionsHome聊天记录存档`，不依赖 E 盘。文件夹不存在时自动创建。启用时，每次修改会保存该条消息完整原记录的 JSON 文件；目录不可用时提示更换位置或关闭存档。关闭后直接保存正文，不生成新的原文文件，已有存档保留。

编辑也可以在 AionsHome 后端关闭时使用。保存只更新原数据库中这一条消息的正文，时间、说话人、附件及思考内容保持不变。AionsHome 的聊天页面刷新后可以看到新正文；已经生成的记忆摘要和导出的 Markdown 文件不会自动重写。

## 外观、CSS 与聊天背景

点击顶部“外观设置”，可以选择苔绿纸笺、莓粉奶霜、雾蓝书页、暖杏手札、墨夜星光五套搭配。套装同时调整按钮、侧栏、聊天气泡、系统提示和特殊消息的颜色；不改变原文或阅读样式。

自定义 CSS 默认预填“标准注释模板”，分节说明全局配色、工具栏、搜索框、侧栏、按钮、聊天背景、角色气泡、你的气泡、头像、名字与时间、内心独白、手表、拍一拍、Markdown、小剧场和手机排版。启用“叠加自定义 CSS”后，代码在所选套装之上生效。使用“新建”“复制”“删除”和名称输入框管理多份预设，切换预设时保留本次编辑；“填入标准模板”可重新填入完整注释代码。

“预览效果”不写入配置，“取消”恢复之前的外观；“保存并应用”会保存全部预设和当前选择，刷新、重启后保留。可在 CSS 编辑框按 Ctrl + Enter 或 Ctrl + S 保存。恢复默认显示仅还原主题、停用 CSS 和移除当前背景，已保存的 CSS 预设仍然保留。若自己写的 CSS 影响操作，按 Ctrl + Shift + 0 临时恢复默认；手机可在查看器地址末尾加 `?safeAppearance=1` 打开，再进入外观设置修改。

“选择背景图片”支持 PNG、JPG、WebP、GIF、AVIF，单张不超过 20 MB。可以选择铺满、完整显示或平铺，并调整图片清晰度。图片存在查看器的 `user-data/backgrounds` 目录，CSS 预设与选择保存在本机 `config.json`；两者均被 Git 忽略，不随源码发布。电脑和已登录的手机均可上传和使用；另一端刷新可读到保存后的设置。“移除背景”只取消当前使用，不删除图片文件。

## 摘句图片卡

顶部“摘句卡”打开独立的卡片编辑器，可以直接输入喜欢的话。每条聊天和小剧场章节旁的“摘句”可以加入这段原文；短消息直接进入卡片，长消息和小说章节展开逐句选择，勾选后点“加入勾选句子”。也可以在正文中划选几句话，再点“用选中文字做卡”。手机可以长按选择原文。

要合并多条消息，先用“选择消息”勾选，再点“制作摘句卡”。选择按原会话和原文顺序整理，聊天和小剧场均支持。卡片文字、换行、标题和落款都可以编辑，也能分别开关落款、日期和小标记；修改只影响卡片，不写回聊天数据库。

“卡片美化”提供配图留白、奶油纸笺、雾林来信、午夜蓝调、粉樱手札五套模板，可调整字体、字号、行距、对齐、留白、底色、文字和点缀色。可以上传自己的配图或使用现有聊天背景，选择上方封面 / 整张背景，调整封面高度或背景清晰度。模板画面用程序绘制，不需要联网下载素材；配图支持 PNG / JPG / WebP / GIF / AVIF，不超过 20 MB，使用 GIF 时保存为当前静态画面。

文字较多时向下延伸为**一张完整长图**，不分张、不截断。预览默认缩小显示整张，勾选“展开长图”可以滚动看清文字。可选 900 / 1080 / 1440 像素宽度，保存 PNG 或 JPG，最短画幅可选自适应 / 方形 / 3:4 / 9:16，内容超过该高度仍自动延长。极长内容会适当降低输出尺寸以适应浏览器；超过单张图片极限会明确提示减少摘句或调小字号，不会静默删字。

卡片中的 `[心里嘀咕：…]` / `【心里嘀咕：…】` 显示为斜体独白，图片中去掉方括号和“心里嘀咕”字样；正文保持普通字体。可在“卡片美化 → 独白颜色”单独换色，随当前浏览器的卡片样式记住。逐句挑选或直接从独白中划选时同样保留独白样式；代码示例和转义标记按原文显示。摘句编辑框仍保留标记，便于识别和编辑，不修改原聊天记录。

点击“保存图片”下载到当前设备，电脑和已登录的手机都可使用，不会自动分享到外部。样式自动保存在当前浏览器；摘句草稿仅保留在当前页面，刷新后不保留。自选配图复用查看器 `user-data/backgrounds` 私有图片目录，不会改变聊天背景；网络访问仍需要访问码登录。

### 分享遮挡 / 马赛克

在正文、标题或落款输入框中选中几个字，点旁边的“遮挡所选”，只遮挡所选的这一次。进入“分享遮挡”可以逐项取消，也能清空手动选择。编辑文字时会调整已有遮挡的位置；打开另一段原文制作新卡片会清空手动范围。

“批量遮挡的字词”每行填一项，自动匹配正文、独白、标题和落款中的全部出现位置，可选择是否忽略英文大小写。按字面匹配，不执行正则表达式。重叠的范围会合并，手动范围和批量匹配可以同时使用。

样式包括方块马赛克、纯色遮挡条、磨砂遮挡、斜线遮挡、自定义文字替换、图案 / 表情替换和自选图片替换。色块保留原位置和宽度，可调颜色及方块 / 斜线大小；文字可以换成“某人”等任意内容，图案可自定义并选择重复次数，图片可上传自己的贴纸并调整宽度。替代文字、图案和图片会重新排版，仍生成一张完整长图。图片上传不影响卡片配图和聊天背景。

原字不绘制到最终图片中，预览、PNG 和 JPG 都使用同一份遮挡结果；文件名也使用遮挡后的标题。编辑框保留原文，随时可暂停或取消遮挡，不修改原聊天记录。只在当前浏览器记住遮挡样式；手动范围和批量字词在刷新后不保留。图片样式未选图或读取失败时，会用色块暂代预览并提示先选择图片，不能把缺图状态直接保存。

## 导出聊天与故事

顶部“导出”打开导出面板，选择范围和文件格式。完整会话从数据库读取全部记录，不受网页当前显示的 80 条限制。点击“选择消息”后可勾选任意消息或章节，翻页、切换会话时保留选择；“全选已加载消息”只选当前已加载内容，导出整个窗口请用“一个完整聊天窗口”。选择仅保留到本页刷新前。

先搜索关键词，再在导出范围选择“所有命中消息”或“命中所在的完整会话”。前者导出每条命中的完整原文，不是搜索摘要；后者导出命中会话的全部上下文。都会取完搜索分页，沿用搜索时固定的全部记录 / 当前会话 / 小剧场范围，导出前会统计记录数量。

“小剧场”可选择整本或勾选章节，按章节编号排列，只导出已写出的正文和插图，不包含大纲、讨论、历史版本或正在生成的章节。EPUB 内置会话、章节目录。

- TXT 使用 UTF-8，保留 Markdown 原文与图片 / 附件说明；图片不嵌入纯文本。
- Word 使用真正的 `.docx`，PowerPoint 使用真正的 `.pptx`，不使用旧版 `.doc` / `.ppt`。文字可以在 Office / WPS 中编辑，幻灯片中的长消息会继续分页，不截断。
- EPUB 适合导入电子书阅读器，PDF 使用固定的纸面排版。PDF 由电脑上已安装的 Edge / Chrome 在独立临时配置中生成，无需安装 Office；其他格式也不依赖 Office 或 AionsHome 后端。

“内容选项”可控制系统消息、普通图片、监控截图、思考内容与聊天时间。系统消息默认跟随阅读设置，手动勾选则准确导出所选消息；监控截图和思考内容默认不导出。图片只从原本地附件读取，不下载外部资源；缺失图片保留说明。常见 PNG / JPG / GIF 可嵌入各图文格式；WebP / AVIF 在 PDF / EPUB 中保留，Word / PPT 中以文字提示代替。音视频保留附件说明、地址与已有转写文字，不把音视频文件打包进去。

生成后交给当前浏览器下载，电脑上导出就存电脑，手机上导出就存手机的下载目录。文件位置按浏览器设置决定。导出不修改原数据库、阅读设置或存档设置；排版使用独立的阅读样式，不包含自定义界面 CSS 和聊天背景。PDF 的中间文件在生成后自动清理，不会永久保存一份额外聊天副本。

随程序附带的导出组件是 docx 9.6.1、PptxGenJS 4.0.1 和 JSZip 3.10.1，无需运行 npm install；授权见 `vendor/licenses`。PptxGenJS 仅把 JSZip 引用改为本地副本。

## 手机浏览和编辑

在 `config.json` 中加入 `"phoneAccess": { "enabled": true }`（示例配置已包含），重新启动查看器。首次开启会生成这台电脑独立的八位访问码和登录密钥，保存在被 Git 忽略的本机配置中；网络访问先登录，电脑本机窗口直接打开。

1. 初次设置，双击 `设置手机访问.cmd` 并允许 Windows 管理员确认。仅给查看器的 TCP 4328 端口创建防火墙规则，来源限同网段和 Tailscale IPv4；自定义端口可运行 `设置手机访问防火墙.ps1 -Port 你的端口`。
2. 启动后，在电脑窗口点击“手机访问”，查看地址和访问码。同一 Wi-Fi 下，手机浏览器打开 Wi-Fi 地址；不同网络下，手机先加入电脑所在的 Tailscale 网络，再打开 Tailscale 地址。无需 Tailscale Serve 或 Cloudflare。
3. 输入访问码进入，浏览器记住登录状态 30 天；点击“退出”可注销。手机可浏览、搜索、调整显示样式和编辑原记录，不需要导入数据库。

电脑和查看器需要运行，AionsHome 后端可以关闭。Wi-Fi 地址可能随网络变化，最新地址显示在“手机访问”面板；Tailscale 地址取自当前电脑的网卡。手机通过 HTTP 打开这些地址，Tailscale 路径由 Tailscale 连接传输。

小屏幕点击左上角打开会话列表或搜索结果，选中后回到整屏正文。图片、监控折叠和 Markdown 格式继续使用。原文存档保存在电脑上，Windows 文件夹选择窗口只从电脑端打开。

手机访问使用配置的固定端口，若端口已占用则提示调整配置，避免自动换端口导致收藏地址失效。设 `"phoneAccess": { "enabled": false }` 后重新启动可恢复只允许本机访问。

## AionsHome 手机 App 自动显示修改

支持现有 `sync_events` 表的 AionsHome 数据库会同时记下一条外部编辑通知。通知只包含消息位置；查看器保存时不需要 AionsHome 后端在线。

将 `integrations/aionshome/external-chat-edits.js` 复制到 AionsHome 的 `aion-chat/static` 目录，并在 `chat.html` 的 `chat.js` 后、`chatroom.html` 的 `chatroom.js` 后各加入：

```html
<script src="/static/external-chat-edits.js?v=20261013-1"></script>
```

首次刷新聊天页加载这个脚本后，手机 App 和网页在前台每两秒检查外部编辑。只更新已加载的对应消息，保留历史记录和滚动位置；回复生成或消息编辑结束后再应用待处理的修改。

聊天记录和附件仍来自原 AionsHome 数据目录。程序文件夹可以移动；如果原数据目录的位置变化了，更新 `config.json` 即可。外部链接及已经删除的附件需要原文件仍然可用。
